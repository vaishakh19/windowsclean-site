Privacy

Last updated: October 22, 2026

Pre-launch notice

The website can start a Dodo Payments test checkout. Test mode does not collect a real payment. Live checkout remains disabled; complete operator contact details will be published before any live sale.

What the app does on your PC

Windows Clean scans the drive or folder you select on your Windows device. Scan history, preferences, and license state are stored in the app’s local storage. The scan results are not included in the app’s Dodo Payments license requests.

License activation

In a build configured for Windows Clean Pro, the app sends the license key you enter, a device label, and the license instance identifier when applicable to Dodo Payments. It uses Dodo’s public license activation and validation endpoints. The merchant API key is not included in the app.

The website sends a fixed product and quantity to the Dodo test API to create checkout sessions. The Vercel backend keeps the Dodo API key and webhook secret server-side. Dodo handles checkout and payment information. A signed test entitlement webhook is checked against the Dodo payment record before a license key is issued. The backend does not receive scan contents or the app’s local files.

Website and third-party services

This site links to GitHub for source code and technical support. The site offers test checkout only, and does not offer a waitlist or newsletter signup.

Your choices and questions

You can remove local app data by uninstalling Windows Clean and deleting its remaining app data from your Windows user profile. This also removes local scan history and saved license state.

For technical support, use the Windows Clean issue tracker. Do not post a license key or other private information in a public issue. A private contact route for privacy requests must be added before paid checkout is enabled.
