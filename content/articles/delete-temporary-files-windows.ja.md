# Windows の一時ファイルを安全に削除する方法

Windows の空き容量が少ない場合は、最初に何が容量を使っているかを確認してください。ドライブをローカルでスキャンし、フォルダー、パス、サイズを確認してから操作を選びます。

## 手順を確認しながら進める

Windows Clean では、ツリーマップ、サンバースト、またはファイル一覧で使用容量を確認できます。スキャンは読み取り専用で、ファイルを自動的に削除しません。

## Prüfen Sie Details / Vérifiez les détails / Revisa los detalles / 詳細を確認

削除する前にエクスプローラーで項目を開く、または表示してください。Windows、Program Files、または不明なシステム フォルダーの内容を手動で削除しないでください。

## 4. Windows の空き容量を安全に増やす方法

保持したい個人ファイルは別のドライブに移動します。削除を確定する場合は、必要に応じて復元できるごみ箱を使用してください。

## Regelmäßig prüfen / Vérifier régulièrement / Revisar con frecuencia / 定期的に確認

大きなインストールや更新の後は、定期的に空き容量を確認してください。

インストール、プライバシー、安全な削除については [Windows Clean FAQ](../../faq/) をご覧ください。
