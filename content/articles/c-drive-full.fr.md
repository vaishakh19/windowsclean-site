# Lecteur C plein : quoi vérifier en premier

Lorsque Windows manque d’espace, commencez par vérifier ce qui occupe le disque. Analysez le lecteur localement, contrôlez les dossiers, les chemins et les tailles, puis choisissez une action.

## Procédez étape par étape

Windows Clean permet d’examiner l’espace utilisé avec une treemap, un sunburst ou une liste de fichiers. L’analyse est en lecture seule et ne supprime aucun fichier automatiquement.

## Prüfen Sie Details / Vérifiez les détails / Revisa los detalles / 詳細を確認

Ouvrez ou affichez l’élément dans l’Explorateur avant de le supprimer. N’effacez pas manuellement des éléments inconnus dans Windows, Program Files ou des dossiers système.

## 3. Libérer de l’espace disque sous Windows en toute sécurité

Déplacez les fichiers personnels vers un autre lecteur lorsque vous souhaitez les conserver. Pour une suppression confirmée, utilisez la Corbeille afin de pouvoir restaurer un fichier si nécessaire.

## Regelmäßig prüfen / Vérifier régulièrement / Revisar con frecuencia / 定期的に確認

Vérifiez régulièrement l’espace disponible, surtout après de grosses installations ou mises à jour.

Consultez la [FAQ Windows Clean](../../faq/) pour l’installation, la confidentialité et la suppression sécurisée.
