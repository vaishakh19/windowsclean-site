# Temporäre Dateien in Windows sicher löschen

Wenn unter Windows der Speicher knapp wird, sollten Sie zuerst prüfen, was Platz belegt. Scannen Sie das Laufwerk lokal, prüfen Sie Ordner, Pfade und Größen, und handeln Sie erst danach.

## Schritt für Schritt vorgehen

Mit Windows Clean können Sie die Belegung als Treemap, Sunburst oder Dateiliste prüfen. Ein Scan ist schreibgeschützt und löscht keine Dateien automatisch.

## Prüfen Sie Details / Vérifiez les détails / Revisa los detalles / 詳細を確認

Öffnen Sie die Datei oder den Ordner im Explorer, bevor Sie etwas entfernen. Löschen Sie keine unbekannten Inhalte aus Windows, Program Files oder Systemordnern von Hand.

## 4. Windows-Speicherplatz sicher freigeben

Verschieben Sie persönliche Dateien bei Bedarf auf ein anderes Laufwerk. Verwenden Sie für bestätigte Löschungen den Papierkorb, damit sie wiederhergestellt werden können.

## Regelmäßig prüfen / Vérifier régulièrement / Revisar con frecuencia / 定期的に確認

Kontrollieren Sie Speicherplatz regelmäßig, besonders nach großen Installationen oder Updates.

Weitere Informationen zu Installation, Datenschutz und sicherem Löschen finden Sie in den [Windows-Clean-FAQ](../../faq/).
