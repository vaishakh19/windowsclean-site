Product and purchase status

Last updated: October 22, 2026

Test mode only: no live sales.

The Windows Clean Pro checkout on this site uses Dodo Payments test mode. Test checkouts do not charge real money and do not create a live purchase. The test product is configured for a one-time $12.99 USD price, permanent license, and one-device activation. Payment and entitlement settings must be verified in Dodo before any live sale can be enabled.

Before paid sales begin

Windows Clean will publish final seller, support, cancellation, and refund details before enabling live checkout. Those terms will identify the seller and support contact, explain the license and device limit, and state the applicable cancellation and refund rules. No device, refund, or support policy is promised by this pre-launch page.

Current software status

The Windows Clean project is available in its source repository. This site offers test checkout only. Product downloads and live paid checkout are not enabled.

For technical questions, use the public issue tracker. Do not post license keys or private information there.
